# Skill Editing

Skills degrade when features are appended instead of integrated. Every edit must preserve cohesion.

**Don't:**
- Append new features as standalone sections at the bottom
- Duplicate guidance across sections
- Order by when written rather than workflow order
- Create separate templates when existing ones can be extended

**Do:**
- Integrate into existing workflow steps, not appendices
- Consolidate shared structure with per-mode callouts
- Match section order to workflow order
- Extract duplicated guidance into shared sections
- Read top-to-bottom before and after editing
